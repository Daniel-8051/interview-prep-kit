# Corpus

One markdown file per project you've worked on, in your own words. Your CV, behavioural answers and design examples all come from here.

## Adding a project

Create `corpus/<project-name>.md` and brain-dump everything you remember:

```markdown
# <Project name>

## Dump

What it was, why it existed, what you did, what went wrong, numbers, people involved.
Raw and messy is fine. Don't polish it.
```

Then run the sceptic on it ("grill me about <project-name>"). It appends questions to the bottom. Answer them inline under each `A:`, in your own words.

Keep running rounds until one lands nothing. Then the entry is done. Entries should finish, not grow forever.
