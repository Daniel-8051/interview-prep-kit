# Applications

One folder per job, created by the recruiter: `applications/<company>-<role>/`.

Each folder holds:

- `jd.md` — the job description, saved verbatim.
- `analysis.md` — what the role really needs, and how you map against it.
- `draft-bullets.md` — CV bullets you write for this role, for the recruiter to grade.
- `cv-tailored.md` — only if you asked the recruiter to write the CV for you.

Anything job-specific lives here, never in `corpus/`.
